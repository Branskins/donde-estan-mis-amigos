`SpacingScale` renders the 4px spacing scale (`space-1` through `space-16`) used for all layout rhythm. **Authoritative reference for any spacing decision.**

```tsx
import { SpacingScale } from "@portfolio/ui";

<SpacingScale />
```

Takes no props. Use the `var(--space-*)` tokens shown here directly — never a raw pixel value.
